# Векторизация подписи

`src/components/signature/signature-data.ts` сгенерирован из фотографии подписи (красные чернила на чёрном):

1. Красные пиксели выделяются в маску, фон фотографии отбрасывается.
2. По маске строится гладкий контур чернил: он заливается и даёт точную форму подписи.
3. Скелет маски превращается в граф штрихов. Порядок и направление штрихов (`order.json`) заданы вручную, как пишется подпись.
4. На сайте маска-перо идёт вдоль этих штрихов и открывает контур, а после прорисовки подпись остаётся целиком.

Перегенерировать (Python 3, пакеты numpy, scipy, scikit-image, opencv-python, pillow):

```bash
python3 vectorize.py signature.jpg sig.json preview.png "$(cat order.json)"
```

`preview.png` показывает штрихи с номерами. По нему удобно поправить `order.json`: каждый штрих — список `[номер ребра, развернуть 0/1]`.
Потом перенесите `outline` и `strokes` из `sig.json` в `signature-data.ts`.
