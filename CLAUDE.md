# Kamui Collection — памятка для Claude

Сайт **kamui-collection.ru**: лимитированная коллекция бильярдного мела Kamui × Iosif Abramov (Limited Edition 0.98 β).
Одностраничный магазин одного товара (+ подарочные наборы и опт). Next.js 16 · React 19 · TypeScript, без UI-библиотек.
Подробности — `README.md`. Соседний проект — интернет-магазин abramov.shop (отдельный репозиторий).

## Как общаться

- Владелец не программист. Отвечать **по-русски, простыми словами**; итог — что изменилось для покупателя или продавца.
- Если задача трогает деньги, остаток или данные покупателей — сказать, что проверено и чем.

## Выкладка

- Работа идёт в ветке `claude/…`. **В `main` заливать только по команде владельца** («заливай»).
- Сайт — Timeweb Cloud App Platform по `Dockerfile`, автодеплой при push.
  В README указана ветка `site`, но в GitHub её нет — с какой ветки сейчас выкладывается сайт, **уточнить у владельца** и поправить здесь.
- Автотестов и проверки на GitHub в проекте нет. Перед заливкой обязательно: `npx tsc --noEmit` и `npm run build`.
- Настройки магазина (не секреты) — в `Dockerfile` (`ENV …`); секреты (ключи ЮKassa, СДЭК, Google Таблицы) — только в панели хостинга.

## Устройство

| Что | Где |
|---|---|
| Главная, разделы, форма заказа | `src/app/page.tsx`, `src/components/sections`, `src/components/purchase` |
| Цена, опт (от 10 шт.), наборы, реквизиты, фото | `src/config/products.ts`, `src/config/site.ts`, `src/config/gallery.ts` |
| Остаток: `TOTAL_STOCK − (SOLD_COUNT + оплачено на сайте)` | `src/config/stock.ts`, `src/lib/stock.ts`, склад — `src/lib/warehouse.ts` |
| Заказы: проверка формы, номер, хранилища (Google Таблица / база / файл) | `src/lib/orders` |
| Оплата: ЮKassa (Россия), Робокасса (из-за рубежа) | `src/lib/payments` |
| Доставка СДЭК: города, ПВЗ, карта, расчёт, автоотправления | `src/lib/delivery`, `src/app/api/delivery` |
| Письма покупателю | `src/lib/mail` |
| База (PostgreSQL Timeweb, необязательна) | `src/lib/db` |
| Английская версия и рынки | `src/app/en`, `src/i18n` |
| Отчёт продаж и склад для владельца | `src/app/sales` (`/sales?token=…`) |
| Скрипт Google Таблицы | `integrations/google-sheets/apps-script.gs` |

- Диск контейнера стирается при каждом обновлении: заказы хранятся в Google Таблице (`ORDERS_FILE_STORE=false`) и/или в базе.
- Деньги в рублях (цена 3 500 ₽, опт 3 000 ₽ от 10 шт.; из-за рубежа — в долларах). Время — Москва.
- Дизайн «Premium Sport / Black Label», шрифты Bebas Neue, Oswald, Montserrat лежат в проекте.

## Чего не делать

- Не менять цену, опт и остаток без прямой просьбы владельца.
- Не писать данные покупателей в логи и сторонние сервисы (кроме Google Таблицы заказов, СДЭК и платёжных систем).
- Не добавлять внешние шрифты, счётчики и библиотеки без необходимости — сайт должен грузиться быстро.
- 152-ФЗ: согласие на обработку ПДн в форме обязательно; политика и согласие — `src/app/privacy`, `src/app/consent`.
