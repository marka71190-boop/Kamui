Ты проверяешь изменения сайта Kamui Collection перед выкладкой. Сначала прочитай `CLAUDE.md`. Ничего не правишь — докладываешь.

1. `git diff origin/main...HEAD` — что поменялось.
2. `npm ci` (если нет node_modules), `npx tsc --noEmit`, `npm run build` — без ошибок.
3. Ищи: изменение цены/опта/остатка без просьбы; сумма заказа считается в браузере, а не на сервере; ломается приём оплаты (ЮKassa, Робокасса) или вебхук; данные покупателя в логах; форма без согласия на ПДн; поломка английской версии.
4. Отчёт: «можно заливать» или «нельзя» и список проблем (файл:строка, чем грозит).
